fix: Auto 切换失败（provider 端口写死导致网关不可达）

报错 Select an available model 的根因:
- cordis.patch.yml 里 dfp-auto 的 baseURL 写死了 127.0.0.1:51373
- 但 DSH 的 Web GUI 端口每次启动都会变，本次是 54220
- 旧端口无人监听 -> DSH 认为该 provider 不可用 -> 拒绝切换

实测确认:
  http://127.0.0.1:54220/dsh-free-pool/v1/models -> 200（正常）
  http://127.0.0.1:51373/dsh-free-pool/v1/models -> fetch failed

修复（两层）:
1. 立即修正当前配置到 54220，并补上缺失的 auto-latency / auto-cost
   两个模型（此前只配了 5 个，选择器里却有 7 个）
2. 根治：插件启动时读取 ctx.webServer.port，自动把 dfp-auto 的
   baseURL 改写成真实端口。端口以后再怎么变都不用管了
   - 只改 dfp-auto 块内的 baseURL 一行，其他 provider 与注释原样保留
   - 端口未绑定完成时每 250ms 重试，最多 10 秒

已验证: 故意把端口写成 :1，启动后自动改回 54220。
